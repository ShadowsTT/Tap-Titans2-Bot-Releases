From download to first tap

Set up in 5 minutes

Tap Titans 2 Bot runs on Windows, macOS and Linux and controls your Android phone over USB. Start with your phone, then follow the steps for your computer.

Your phone

Connect Android

  1. Turn on Developer options

    On the phone, open Settings > About phone > Software information. Tap “Build number” seven times.

  2. Turn on USB debugging

    Open Settings > Developer options and turn on “USB debugging”.

  3. Plug in the phone

    Use a USB data cable. On the phone, tap Allow on “Allow USB debugging?” and tick “Always allow from this computer”. These steps were tested on a Samsung Galaxy S8+; other Android phones name the menus slightly differently.

Your computer

Install the app

Use the file for your operating system from the download page. Replace <version> below with the version you downloaded.

Windows

  1. Run TapTitans2Bot-Setup-<version>.exe, or unzip TapTitans2Bot-<version>-windows-portable.zip and open the app.

  2. The app is not code-signed. If SmartScreen says “Windows protected your PC”, click “More info”, then “Run anyway”.

  3. If the app cannot see a Samsung phone, install Samsung’s “Samsung USB Driver for Mobile Phones”.

macOS (Apple silicon)

  1. On a Mac with M1 or later, open TapTitans2Bot-<version>-macos-arm64.dmg and drag the app to Applications. Intel Macs are not supported.

  2. The app is not notarized, so macOS blocks the first open. Try to open the app once, then open System Settings > Privacy & Security, scroll down and click “Open Anyway”, then confirm.

Linux (x86_64)

  1. For Debian or Ubuntu, open a terminal in your downloads folder and install the .deb: sudo apt install ./tap-titans2-bot_<version>_amd64.deb.

  2. For AppImage, make the file executable with chmod +x TapTitans2Bot-<version>-x86_64.AppImage, then run ./TapTitans2Bot-<version>-x86_64.AppImage. On Ubuntu 22.04+ it may need libfuse2 (on 24.04: libfuse2t64).

  3. If the phone shows “no permissions” on Debian or Ubuntu, install Android udev rules with sudo apt install android-sdk-platform-tools-common, then unplug and replug the phone.

Your first session

Start auto tap

  1. Open the app

    Follow “First-run setup” and pick your phone.

  2. Open Tap Titans 2

    Open the game on your phone, then press “Start” in the desktop app.

  3. Try Pro

    Press “Start 24-hour trial” in the app’s Pro panel. The trial is available once per computer.

Quick checks

If something goes wrong

  • Phone not found: check for a charge-only cable, USB debugging turned off, or an “Allow USB debugging?” prompt you have not accepted.
  • Wrong phone selected: use “Change device” in the app to choose another device.
  • Start is disabled: open “First-run setup”, complete the required prerequisites and press “Re-check”.
